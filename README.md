## الفكرة

خيط أحمر يبدأ أثرًا في الحجر، ثم يتحول إلى زمن وخريطة وقناة ماء وسطر شعر. الفيلم يدمج صورًا حقيقية للحمراء مع لوحتين سينمائيتين تصوّريتين، طبقات ورقية، خرائط وعناصر متجهية ونصوص عربية.

الكاميرا تنساب على زمن 32fps، بينما تتحرك العناصر الداخلية بإيقاع stop-motion عند 8fps. العمق يولّد البارالاكس، والتركيز يتبدل بين الطبقات، مع إضاءة دافئة متحركة وغبار محدود داخل الضوء.

- `assets/generated/cinematic-plate-stone.jpg` و`cinematic-plate-water.jpg` — اللوحتان السينمائيتان كاملتين.
- `assets/cinematic/` — الطبقات المفصولة والمراجع المصغّرة.
- `assets/audio/` — أصول المستخدم ومزيج الصوت الحالي.
- `docs/cinematic-engine.md` — شرح المحرك والتصيير والتحقق.
- `docs/creative-plan.md` — التصور السردي الأصلي وملاحظات التوثيق.

- `CREDITS.md` — المصادر والتراخيص والفصل بين الصور الحقيقية والمادة المولّدة.
- `vendor/` — النسختان المستقلتان من AI Film Studio وmotion-reel، داخل نسخة GitHub.

## إعادة الإنتاج

من بيئة Linux التي تحتفظ بهذه الملفات:

```bash
bash tools/restore_environment.sh
python3 tools/build_cinematic_engine.py
python3 tools/review_cinematic.py
```

يحتاج إعادة التصيير الكامل إلى FFmpeg (توفره حزمة imageio-ffmpeg)، Playwright Chromium والخطوط والأصول المرفقة. `window.seek(t)` يرسم الإطار من الوقت وحده.

```bash
# دون نشر أو استعمال أي بيانات اعتماد:
python3 tools/render_cinematic.py --local-only
```

أداة GitHub تقرأ بيانات الاعتماد من متغير مؤقت في العملية فقط. **لا تضع توكنًا في المستودع أو ملف .env أو أوامر ملتزمة في git.** الأجزاء المنشورة عامة ويمكن استعادتها دون أي توكن:

```bash
python3 tools/restore_checkpoints.py --destination /path/with/enough/space
```

## الحفاظ على الملفات والمساحة

لا يستخدم المشروع مجلد `out`، ولا يحذف المصادر أو الأجزاء بعد التصيير. لا تُحفظ آلاف الصور الوسيطة؛ تُرسل الإطارات مباشرة إلى FFmpeg. الأجزاء الكبيرة تُحفظ محليًا في تخزين التشغيل وتُرفع إلى GitHub قبل الانتقال للجزء التالي. الشيفرة، الأصول، الصوت، manifests ومعاينات الاعتماد محفوظة في مجلدات المشروع الدائمة.

في مساحة Arena ذات سقف يقارب 128 MB، لا تُنسخ النسخة النهائية إلى الملفات الدائمة إلا إذا سمحت الميزانية. تبقى النسخة الرئيسية محفوظة في المستودع، ويمكن توفير نسخة عرض أخف **بنفس 1920×1080 و32fps**؛ الضغط الأخف ليس ادعاءً بأنه بلا فقد بصري.
